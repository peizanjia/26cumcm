# 半径接近 20：策略、正交引导与可行域

2026-09-11。本目录是本次重写的黑箱训练实现；旧面积与“半径越小越好”实验保留历史含义。全部数值是本地合成模拟，不是官方成绩。

## 1. 明确两个不同问题

观测状态 s=(第一测点 x,y，第一观测方向 θ₁)。定义两次观测后可行区域 K 的**最小包围圆半径**

ρ(K)=min_c max_{u∈K} ||u-c||。

它不是面积换算半径，不是第一问直径的一半。复用第一问的两点/三点支持思想，Numba 实现与第一问参考核对。

用户最新要求“越接近 20 越好”，因此训练主目标采用

L₀(s,q)=E[|ρ-20| | s,q]/20。

不是 |E[ρ]-20|，不是 E[ρ]，也不是仅惩罚超过 20 的部分。ρ=0 在这个字面目标下也有 20 m 的偏差；如果实际意图是“≤20 后都算成功”，应使用单侧超限损失，这是另一个目标，不能混报。

精度**可行条件**则取 ρ≤20。选择偏好与可行条件分开：可以在满足精度的候选集合内再优化接近 20、移动距离或后续任务代价。

## 2. NN 只给一个点，如何回答“策略和可行域”

策略是映射 π:s↦q。可行域是集合映射 F:s↦{合格的第二测点}。点映射不包含全部集合信息，两个任务需要分别实现。

本目录给出四个层次：

| 层次 | 定义 | 本轮交付 |
|---|---|---|
| NN 候选策略 | q=π_w(s) | 无引导及正交引导；左右 bool 由外部选择 |
| 均值可行域 | F_mean={q:E[ρ|s,q]≤20} | 网格近似，不保证每次成功 |
| 机会可行域 | F_95={q:P(ρ≤20|s,q)≥0.95} | 样本网格估计，选点独立复核 |
| 稳健可行域 | F_rob={q:sup_{所有允许目标、误差、半径}ρ≤20} | 保守几何候选内集；未求完整连续集合 |

另保存“样本最大值≤20”的掩码，它不能等同于 F_rob。图上连接的色块是网格显示，未证明网格点之间全部可行。

实际策略可以写为 π_F(s)∈argmin_{q∈F(s)} L₀(s,q)，再以移动距离打破同分；若 F(s) 未找到候选，应回报未找到，不能把无约束 NN 的点称为可行。

`policy.candidate_strategy` 不接受目标真值参数，只接受第一测点、方向和候选全局坐标。它根据第一观测后验计算候选集、按经验 F_95 筛选，选接近 20 最好的点；使用独立至少 4096 事件复核选点，复核失败返回 `selected_point=None`。这仍是经验机会约束，不是概率下置信界证书。`feasible_mask` 是原筛选样本的掩码；`independent_validation` 单独保存复核结果。

NN `pi` 只是快速候选点接口，不自动保证可行。未来第三、四问可以从左右可行分支中选择，并把全局路程代价放入策略；不能按未知真目标挑分支。

## 3. 训练与正交引导

网络只接收旋转归一化的第一观测状态。目标坐标不作为网络特征，不给最优动作标签。条件目标样本由 s 的后验分布生成，只用于模拟期望积分；不是向网络泄漏环境中固定的真实目标。

设 θ₂=arg(G-q)+ε₂。方向引导为

L_orth=E[1_{收到有效方向} cos²(θ₂-θ₁) | s,q]。

于是 L=L₀+λL_orth。cos² 在两个方向正交时最小，关于方向反转对称。它是几何先验正则项，不是带 PDE 残差的严格 PINN。

在第一读数归一化为 0 后，令 β=arg(G-q)，均匀误差 ε₂∈[-δ,δ] 可解析积分：

E_ε[cos²(β+ε)] = 1/2 + sin(2δ)/(4δ) cos(2β)。

有效接收概率 γ 由同源隐藏半径 R 的条件均匀分布解析边缘化；使用 γ 加权上述项，near 无方向不加正交损失。因此 L_orth 是未条件归一化的有效方向加权期望，不能通过忽略失联来解读它。主损失仍处罚失联后的大半径；统计额外报告实际失联率与有效方向夹角。

**实际求导方式**：当前 MEC 在 Numba 中计算，不是 Torch 可微算子。对动作 q 的每个坐标使用 ±0.5 m 的公共随机样本中心有限差分，然后用该动作梯度乘 NN 输出对参数的导数，Adam 更新网络。没有声称对 Numba MEC 直接 `backward()`；有限差分与圆多边形、样本积分都有近似误差。

训练配置：

- 4096 状态×128 后验事件；每步 64 状态×32 事件；1800 步，左右分支交替，验证双侧等权。
- λ=0、0.1、0.5，各两个配对初始化，共六模型批量计算。都是从先前半径 NN 微调，其中第二初始化加微小权重扰动；不是六次独立从零训练，也不构成广泛随机种子稳健性研究。
- 训练种子 33260911，验证 34260911，测试 35260911，初始化 36260911/36260912。
- 每个模型按自己的验证总目标保存；部署的无引导/引导模型再按主指标 MAE20 在各自保存模型中选择。测试集不参与选择。引导选中 λ=0.1。
- 计算约 213.70 s。几何通过 CPU Numba 8 线程并行，NN 较小在 CPU 运行，避免几何有限差分反复 CPU/GPU 传输。
- 训练完成后第一次选模读取因 NumPy 标量元数据不兼容 `weights_only=True` 失败；将本轮自生成权重的标量转为 Python float 后恢复选模，无需重训。生产训练代码已修正，当前六份权重均能按 weights_only 读取。

## 6. 保守几何内集：对整个角区间给上界

设 P 是包含真实第一轮区域的外包多边形。先检查所有 P 顶点距候选 q≤1000 m，即保证所有可能目标均收到信号或进入 near。若不满足这一充分条件，暂时只使用第一轮半径的普适上界，并不证明该点不可行。

把第二测量方向的完整 2π 分成720段，每段宽0.5°、中心 α_k。任意段内 θ₂ 的半角1°扇形都包含于以 α_k 为中心、半角1.25°的扩大扇形。因此

U(q)=max_k ρ(P ∩ W(q,α_k,1.25°))

是连续所有第二方向下半径的上界，不依赖目标真值或误差抽样。满足 U(q)≤19.95 的候选保留0.05 m裕量。实现为浮点运算，没有区间算术误差证书；可以称为模型下的保守几何候选内集，不能称为完整连续稳健可行域。

各局部取51×51=2601候选：原点0个、边界1144个、斜边界967个通过此界。边界最近通过点 (1596,-98)，半径上界19.331 m；斜边界最近通过点 (1124,1088)，上界19.869 m。最近仅针对这些候选网格。

![保守内集候选](results/conservative_candidates.png)

对应 `robust.conservative_bounds` 可用来核验 NN 或其他算法提出的第二点。它返回上界而不是目标真值分数；未通过不能反推不可行。

## 7. 其他可尝试的引导（本轮没有冒充已训练）

1. **接收保证引导**：惩罚 max_{g∈P}||q-g|| 超过1000，或将候选限制在对应集合，针对现有失联尾部。
2. **单侧精度门槛**：E[relu(ρ−20)] 或超限概率，与“≤20”任务更一致；会改变当前字面目标。
3. **尾部风险**：对高分位或 CVaR 加权，避免少量失联被平均数掩盖。
4. **移动代价**：在可行域内最小化移动距离，适合作为第三、四问的全局规划代价。

这些项都可以从第一观测可行区域/后验计算，不需要输入实际未知目标；但它们不能替代题目约束，也不能保证加入后一定提升结果。
