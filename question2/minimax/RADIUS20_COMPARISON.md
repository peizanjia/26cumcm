# 新 radius20 神经网络与直径 minimax 的对比

对比对应协作者提交 `56d71c42248d5a9019bfb0100d4233a2f5a3f5a2`。结论先行：新网络不是“最小化直径”，而是最小化

\[
\mathbb E\lvert \rho(K)-20\rvert/20,
\]

其中 \(\rho(K)\) 是候选区域的最小包围圆半径。这个目标会同时惩罚高于和低于 20 m 的结果，因此不同于“直径越小越好”，也不同于“半径不超过 20 m”。

## 当前可复核状态

GitHub 新提交包含训练、评估和推理代码，但没有包含推理所需的 `plain.pt`、`orthogonal.pt`，也没有 `results/evaluation.json` 或逐事件输出。因此本地不能真正加载新网络、在相同样本上做配对检验。下表把本地 minimax 的 128 次独立仿真与新代码 README 公布的 1,048,576 个“事件×分支”统计并列；它是临时、非配对对比。

| 指标 | 直径 minimax（本地） | 新 NN，无引导（作者报告） | 新 NN，正交引导（作者报告） |
|---|---:|---:|---:|
| 平均最小包围圆半径 / m | **23.633** | 24.240 | 24.225 |
| 平均 \(|\rho-20|\) / m | 5.681 | **5.157** | 5.170 |
| P95 半径 / m | 41.080 | **37.800** | 37.895 |
| 最大半径 / m | **50.910** | 750.114 | 750.114 |
| \(P(\rho\le20)\) | **39.06%** | 31.10% | 31.16% |
| 失联率 | **0** | 0.02794% | 0.03090% |
| 接收充分条件认证率 | **100%** | 未报告 | 未报告 |

minimax 的原生直径指标是：均值 47.264 m、P95 82.160 m、最大 101.820 m；新网络没有报告直径，不能用半径直接冒充直径。仅能使用一般关系 \(\rho\le D\le2\rho\)，所以新 NN 的平均直径只能界定在 24.240–48.479 m，P95 只能界定在 37.800–75.599 m，不能得出其精确直径统计。

## 如何解读

- 按新网络自己的双侧目标“尽量接近 20 m”，作者报告的新无引导网络更好：MAE20 比本地 minimax 小约 0.524 m。但两批样本和几何规则不完全一致，不能当作显著性结论。
- 按“越小越好”或“满足不超过 20 m”，minimax 更符合目标：平均半径更小，\(\rho\le20\) 比例更高。
- 按极端可靠性，minimax 优势明显：候选点全部具有解析接收充分证书，本地没有失联；新网络少量失联会把最大半径推回约 750 m。
- 按可解释性与候选区域，minimax 直接输出带上界的近优候选点集合；新 NN 的点输出本身不构成候选区域，仓库另用抽样网格和保守几何内集补充。
- 新仓库评分明确省略第二次接收所蕴含的 1500 m 候选约束；本地官方口径加入该约束。当前 128 个安全策略样本中它没有改变数值，但这不保证所有场景都相同。

## 完成严格同场对比还缺什么

请协作者把至少 `radius20/checkpoints/plain.pt`（若比较引导模型，再加 `orthogonal.pt`）push 到仓库。最好同时上传 `results/evaluation.json` 和 `evaluation_samples.npz`。拿到权重后，应固定同一组状态、后验事件和左右分支，对所有动作同时计算：候选集直径、最小包围圆半径、面积、失联率、解析接收证书与计算时间，再做按状态聚类的配对区间。
