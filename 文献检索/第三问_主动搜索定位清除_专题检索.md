# 第三问：主动搜索、定位与清除的文献及建模路线

检索日期：2026-09-11。范围：题目原文、出版社/期刊官网、作者或大学机构仓储、公开网页中可检索的中文论文记录。未登录知网，不声称已穷尽其全文库。下文明确区分原论文方法、本题改造建议和命题来源线索。

## 1. 结论与题目边界

用户提出的“边摸清周围源的位置、边沿途清除、最终覆盖全频道全地图”，对应**主动多目标搜索与定位（active multi-target search and localization）+ 自适应信息路径规划（adaptive informative path planning）+ 感知覆盖验证**。完整问题可写为带终止条件的部分可观测随机最短路；不确定性没有概率模型时，也可采用集合成员估计和鲁棒滚动规划。

已核对 `B题.pdf` 第1—4页及附件1/2中的协议：

- 起点固定为原点，初始频道为1，不需要另找起点；要优化的是首次扫描与后续动作。
- 10—16个静止全向源、20个频道、每个源的频道不同。频道本身就是目标标签。
- 仅能停下来逐频道检测，返回无信号、near或示向度；接口不返回连续RSS场强值。测向误差有界于±1°，同地点重复检测不会改变误差；原题没有给出独立高斯噪声假设。
- 各源有效接收半径为1000—1500 m；20 m内光学精确定位并清除必成功。
- 测量5 s，检测频道变化1 s，移动距离/5 s；clear失败3 s、成功5 s。clear的频道参数不改变测向机频道，也不产生切换成本。
- 可在任意位置结束，不要求返回原点。对同一案例且全部清除时，最小化总时间与最小化总时间/源数等价；该指标不是各目标首次清除时刻的平均值。

不必每一小块地面都亲自走到，也不必在每个停靠点测完全部频道。需要证明每个未解决频道的潜在源位置已经被有效排除，或该频道的源已经清除。“走过某条路”本身不会产生检测覆盖，因为移动中不能检测。

## 2. 检索领域与关键词

| 决策问题 | 中文检索词 | 英文检索词 |
|---|---|---|
| 未知目标在哪里、还有多少 | 主动多目标搜索；未知数量目标搜索；多辐射源搜索定位 | active multi-target search; unknown number of targets; multiple radio source localization |
| 走到哪里才能更快定位 | 主动感知；纯方位定位；观测器机动优化 | active sensing; bearing-only localization; sensor trajectory optimization |
| 探索新源还是精化已有源 | 探索与利用平衡；信息增益；信息驱动路径规划 | exploration-exploitation; informative path planning; belief-space planning |
| 停下来测，还是继续走 | 间歇测量；事件触发感知；测量成本 | intermittent measurements; event-triggered sensing; costly observations |
| 清除顺序及绕行代价 | 在线路径规划；邻域旅行商；滚动时域规划 | online routing; traveling salesman problem with neighborhoods; rollout planning |

“SLAM”不是本题的主关键词：机器狗自身位置和区域边界已知，未知的是源。“避障路径规划”也不是核心，因为题目未给障碍物。“抗干扰通信”大量研究避免干扰或保持链路，目标与本题主动定位并清除不同。

## 3. 最值得精读的论文

### A. 整体策略最贴近：探索、精化和行动成本统一规划

**Bilal Yousuf, Radu Herzal, Zsófia Lendek, Lucian Buşoniu. Multi-agent active multi-target search with intermittent measurements. Control Engineering Practice, 153 (2024), 106094.**

- [出版社与DOI](https://doi.org/10.1016/j.conengprac.2024.106094)；[作者公开全文](https://busoniu.net/files/papers/cep24-bilal.pdf)。核验：出版社索引内容、作者全文可检索内容及书目。
- 原方法：未知数量静止目标，粒子PHD估计，联合考虑移动成本、目标位置精化和环境探索；航点决策和测量时刻分开，允许事件触发测量。
- 本题用途：把“探索未知频道区域、补测已知源、前往清除”放入统一候选动作集。这是整体流程的第一优先参考。
- 限制：原论文的检测和定位模型不同；没有本题逐频道操作及20 m清除条件。这里的改造不属于原文已经验证的算法。频道唯一时不必照搬PHD。

### B. 停测与移动权衡最贴近：直接优化定位所需时间

**Folker Hoffmann, Hans Schily, Alexander Charlish, Matthew Ritchie, Hugh Griffiths. A Rollout Based Path Planner for Emitter Localization. FUSION 2019, 1–8. DOI:10.23919/FUSION43075.2019.9011368.**

- [研究机构原始记录](https://publica.fraunhofer.de/entities/publication/68b62762-82f2-4e89-b5c0-9bf363b1ae20)；[DOI](https://doi.org/10.23919/FUSION43075.2019.9011368)。核验：机构摘要及书目；机构页面实时访问有反爬，搜索索引可读。
- 原方法：单移动平台、有噪声方位观测、测量需要停留；使用rollout比较多测量和移动到更好位置，优化达到给定定位精度的时间。
- 本题用途：直接借鉴移动/停测的总时间评价，终止精度改为能够保证20 m内清除。
- 限制：这是会议论文，不包装成高分期刊；它不是未知多源全域搜索的完整方案。

补充长文：**Folker Hoffmann. Sensor Path Planning for Emitter Localization. UCL博士论文，2023。** [机构全文](https://discovery.ucl.ac.uk/id/eprint/10165161/2/Folker%20Hoffmann%20-%20Sensor%20Path%20Planning%20for%20Emitter%20Localization%20-%20Final.pdf)。适合追溯同一研究线的模型、推导和实验，不作为本题命题来源证据。

### C. 高水平机器人期刊：未知多个无线电源的主动搜索

**Chang Young Kim, Dezhen Song, Yiliang Xu, Jingang Yi, Xinyu Wu. Cooperative search of multiple unknown transient radio sources using multiple paired mobile robots. IEEE Transactions on Robotics, 30(5), 1161–1173, 2014.**

- [DOI](https://doi.org/10.1109/TRO.2014.2333097)；[Rutgers机构书目与摘要](https://www.researchwithrutgers.com/en/publications/cooperative-search-of-multiple-unknown-transient-radio-sources-us/)。核验：机构记录。
- 原方法：成对机器人利用信号强度比构造位置后验，结合高概率区域聚类和局部熵选择动作。
- 本题用途：未知多源的概率地图和自适应搜索思想。
- 限制：多机器人、暂态匿名信号、RSS比值；第三问是单机器人、稳定且可按频道识别的源，不能照搬感知模型。
- 期刊指标：IEEE RAS官网明确标注“T-RO JCR Impact Factor 11.1 in 2025”。这是官网标注口径，不能标成2014年的影响因子或未经核验的2026 JCR指标。[官方指标来源](https://www.ieee-ras.org/publications/t-ro/)

相关扩展：**Chang-Young Kim, Dezhen Song, Jingang Yi, Xinyu Wu. Decentralized Searching of Multiple Unknown and Transient Radio Sources with Paired Robots. Engineering, 1(1), 58–65, 2015.** [官方全文](https://www.engineering.org.cn/engi/EN/10.15302/J-ENG-2015010)。其引言明确提到用移动机器人搜索并使传感器失效的任务背景，主体方法仍是分布式搜索及信息同步；不能当作第三问单机清除算法。

### D. 射频场景最直接：按搜索阶段切换策略

**Tianchen Ruan, Yang Huang, Qiuming Zhu, Caiyong Hao, Qihui Wu. Multi-Stage RF Emitter Search and Geolocation With UAV: A Cognitive Learning-Based Method. IEEE Transactions on Vehicular Technology, 72(5), 6349–6362, 2023.**

- [IEEE原文记录](https://ieeexplore.ieee.org/document/10016683/)；[DOI](https://doi.org/10.1109/TVT.2023.3235498)。核验：IEEE摘要和元数据，作者ORCID交叉核对。
- 原方法：按信噪比条件采用不同轨迹策略，将DOA估计与强化学习等方法用于搜索定位。
- 本题用途：支持搜索阶段与精定位阶段采用不同策略，而不是全程一个固定步长。
- 限制：本题不提供SNR读数，不能直接使用原文的SNR切换门限；建议改用候选区大小、是否收到信号和预计清除成本。单源方法仍需加多频道调度。

### E. 信息路径规划的理论参考

## 6. 本题建模建议：以下为改造方案，不是文献原结论

### 6.1 每频道同时保留状态和候选集合

令目标区域D为半径1800 m圆盘，频道c的状态为未判定、已发现未清除、已清除或已证明无源。条件于该频道存在源时，候选集记为Ω_c，初始为D。

- 在p测得示向度θ：与方向θ±1°、距离不超过1500 m的扇区相交；direction还意味着距离大于5 m。
- 在p无信号：第三问可安全排除B(p,1000)。1000—1500 m环带仍不确定，不可全部排除。
- 在p收到near：候选集与B(p,5)相交，可就地clear。
- 对已确认存在的源clear失败：可排除B(p,20)。clear成功后，将频道永久记为已清除。

更紧的实现可联合维护位置与有效半径r_c∈[1000,1500]；上述位置集合更新是较简单、保守的实现。题目没有给概率分布时，不把均匀先验或高斯噪声写成官方设定。

### 6.2 将三种动作交错执行

候选动作包括：探索尚未排除的区域与频道；在较好交会几何处补测已有源；在可清除位置执行clear。用短时前瞻估计动作后的剩余工作量，每执行一次动作便更新计划。

测量动作成本：

\[
\Delta t_{\mathrm{measure}}=\frac{\|p-x_t\|}{5}+5+\mathbf{1}(c\ne c_t).
\]

clear动作成本为移动时间加3或5秒，不包含频道切换。若引入概率模型，完整决策可以写为：

\[
V(b,x,c)=\min_a\{\Delta t(a)+\mathbb E[V(b',x',c')\mid b,a]\},
\]

其中b包含各频道存在性和位置的不确定性；对clear，其即时成本也应对成功/失败取期望。这个式子用于说明目标，实际不必求解完整POMDP，可采用候选动作+rollout。

轻量启发式可以评价“预计新增探索面积、候选区缩小量、清除收益”相对于增量时间；这些指标须归一化并通过演练校准，不能宣称简单加权自动得到全局最短时间。

### 6.3 只定位到足以清除即可

鲁棒清除条件是存在清除点q，使：

\[
\sup_{g\in\Omega_c}\|q-g\|\le20.
\]

若Ω_c的最小包围圆半径≤20，则圆心是一个保证成功的清除点；还可在所有可保证成功的点中选距离当前点近的一个。候选点集为各B(g,20)的交集，不能与最小包围圆混淆。不需要把位置继续估得极精确。

已知目标位置之后的访问顺序可借鉴开放路径TSP/TSPN；未知目标尚未发现时，静态TSP不能替代探索决策。“沿途立即清除”也非总是最好，应比较增加的绕行时间与后续回访节省。

### 6.4 用覆盖证书保证无遗漏

对始终未收到信号、未清除的频道c，记其全部无信号测点为P_c。若：

\[
D\subseteq\bigcup_{p\in P_c}B(p,1000),
\]

则该频道不可能还有源：若有源，其必在某测点1000 m内，应被检测到，与无信号矛盾。

每个频道都已清除或已证明无源时即可退出。还可利用上限：一旦成功清除16个不同频道的源，即已完成；清除10个不能据此退出。

实现时可让探索动作尽量增加未排除区域的覆盖，并在剩余缺口上调用固定覆盖兜底，避免长期只追逐已发现目标。严格保证需几何证明或带保守余量的覆盖判定；仅做有限网格采样不能当作全域覆盖证明。本条件只用于第三问，第四问定向源需另行处理角度盲区。
