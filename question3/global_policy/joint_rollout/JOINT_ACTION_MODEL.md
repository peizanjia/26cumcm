# 联合停点、信息收益与路线代价模型

日期：2026-09-12。本文把“靠近当前目标”和“对其它频道产生正交测量收益”放到同一个以秒为单位的决策模型中。模型只使用模拟器已经公开的观测、位置、频道和覆盖状态；真值只用于离线评估。

同日核验更正：原稿在完整剩余价值后再加终端值、在清除立即成本中加入失败续策、以及从净 VOI 再扣扫描费，存在重复计费；以下已修正。原来的协同收益公式混用了多个反事实基准，也改为同一完成目标下的可执行策略比较。保留更正记录，不能据旧终点/单源消融推定未实现跨频道方案的收益上限。

## 1. 状态与动作

每个频道 (c) 维护联合后验 (b_c(x,R))，其中 (x) 是源位置，(R) 是接收半径。状态写成

\[
s=(q,k,\{b_c\}_{c=1}^{20},\mathcal U,\mathcal C,\mathcal F),
\]

分别表示机器狗位置、当前频道、各频道后验、未清除源、覆盖证书和未关闭搜索前沿。

一次联合动作定义为

\[
a=(y,A,e),
\]

其中 (y) 是经停点，(A) 是在 (y) 扫描的频道集合，(e) 是完成本次服务后准备衔接的下一入口。它同时决定三件事：移动到哪里、在哪些频道付出测量时间、结束后往哪一片区域走。

## 2. 用秒统一距离和信息价值

候选动作的立即代价为

\[
C_0(s,a)=\frac{\|y-q\|}{5}+5|A|+\operatorname{switch}(k,A)+C_{clear}(s,y,A),
\]

其中每次 `/measure` 为 5 s，频道切换按实际命令序列计 1 s。若动作包含一次试清除，`C_clear=p_hit×5+(1−p_hit)×3` 只计该次清除的立即费用。失败后的续策只能放进后续价值，不能再放入 `C_clear`。若扫描后才决定是否清除，应按该自适应动作树逐节点计费，未实际执行的分支不收费。

定义完整状态的剩余时间价值 (V(s))。执行 (a) 后得到观测 (z)，后验变为 (s_{a,z})，则

\[
Q(s,a)=C_0(s,a)+\mathbb E_z[V(s_{a,z})],
\]

选择 (Q) 最小的候选，并且只执行第一步；收到真实反馈后重建后验，再次计算。这就是滚动规划。

实际只能有限前瞻时，用 `V_H` 累计窗口内动作时间，并在窗口末态 `s_H` 加一次 `h(s_H,e)`，估计尚未完成的已知源与覆盖工作。于是 `Q_H=C_0+E[V_H+h]`。`h` 与 `V_H` 必须对应不重叠的工作；若用完整 `V`，不可再叠加 `h`。

## 3. 正交测量如何进入模型

假设频道 (c) 的位置后验是一个细长区域，粒子协方差为 (Sigma_c)，主轴方向为 (u_c)。在候选点 (y) 处，指向后验中心的视线方向为

\[
v_c=\frac{\mu_c-y}{\|\mu_c-y\|}.
\]

若已有细长条沿 (u_c)，新测向与旧条近似正交时，交集收缩最大。可用

\[
g_c(y)=1-(u_c^\top v_c)^2=\sin^2\phi_c
\]

作为几何预筛分数。更稳健的连续指标来自测向 Fisher 信息。令

\[
H_c(y)=\frac{1}{\sigma_\theta^2 r_c^2}(I-v_cv_c^\top),
\]

其中 (r_c=\|\mu_c-y\|)，\(\sigma_\theta\) 是角度误差尺度，则协方差收缩近似为

\[
\Delta_c(y)=\frac12\log\det\left(I+\Sigma_cH_c(y)\right).
\]

粒子模型中不必依赖高斯近似：对每个候选点和共同随机情景生成 `signal/no_signal + bearing`，更新粒子权重或几何区域，直接计算后续剩余时间。\(g_c\) 和 \(\Delta_c\) 只用于减少候选数量，最终排序使用时间期望。

## 4. “近距离”和“多频道收益”的博弈

对频道集合 (A) 定义时间价值

\[
\operatorname{VOI}(s,y,A,e)=Q_H(s,a_{\rm reference})-Q_H(s,(y,A,e)).
\]

基准动作 `a_reference` 与候选采用同一窗口、终端值和共同随机情景。当净 VOI>0 时，试探和额外扫描的预期节省已经超过移动、测量、切频及机会成本，动作才值得执行；不再另扣同一笔费用。这样不需要人为指定“距离权重”和“信息权重”的单位换算。

频道之间的共享收益为

\[
S(A)=Q_H(s,\pi_{\rm separate}(A))-Q_H(s,\pi_{\rm joint}(A)).
\]

两边均为从同一状态出发、服务同一任务集合的可执行策略：前者分别选择测点，后者共享停点；每条真实移动、扫描和切频只计一次。共享停点可能减少移动，也可能牺牲观测角度，故 `S` 的符号须计算，不能凭共享形式保证为正。原稿 `VOI(A)−ΣVOI({c})` 混用多个基准，可能机械地重复抵扣移动成本，不宜当作协同收益。

由于完整频道结果组合会指数增长，在线近似采用公共随机情景：每个情景同时生成所有 (c\in A) 的反馈，联合更新后一次运行短时域续策。频道后验独立时可用单频道结果作初筛，再对前 6–10 个频道组合做联合复核。

## 5. 候选点和频道集合生成

每次重规划生成以下候选点：

1. 当前频道的直接测量点、MEC 中心、最高后验质量点。
2. 细长后验主轴两侧的正交候选点，优先保留 (g_c(y)>0.7) 或 (Delta_c(y)) 较大的点。
3. 其它频道的正交候选点和后验中心附近点。
4. 下一分区覆盖前沿、已知源服务点和到下一入口的衔接点。
5. 当前点附近的安全清除点。

对频道先计算单频道边际价值

\[
m_c(y\mid A)=Q_H(s,(y,A,e))-Q_H(s,(y,A\cup\{c\},e)).
\]

这是在同一个候选停点、同一个现有频道集合上增加频道 `c` 的净边际收益，已包含增加的测量费与实际扫描顺序引起的切频费。只保留 `m_c>−τ` 的频道参与枚举或增量贪心，最终执行要求净收益为正；覆盖证书必需的频道则由完成约束保留。若 `A` 为空且必须依附 `/measure` 才能移动，基准必须使用一个实际可执行的移动动作，不能虚构免费移动命令。

## 6. 数值优化流程

建议采用三层计算：

1. **几何预筛**：用距离、\(g_c\)、覆盖缺口和下一入口距离，从几百个网格/主轴候选保留 30–60 个点。
2. **SAA 粗评估**：用 64–128 个共同随机情景计算所有 ((y,A,e)) 的 (Q)，保留前 6–10 个。
3. **连续精化和独立复核**：以保留点为初值，用差分进化、Powell 或模式搜索优化 (y)；最终用新的 512–2048 个共同情景复核。量化角度和命中/失败分支导致目标不光滑，不把普通梯度下降当作全局优化证明。

每一步只执行复核后第一名，收到真实观测后重算。所有候选必须使用同一批随机情景，否则几十秒以内的差异会被蒙地卡罗噪声污染。

## 7. 与注意力模型的关系

注意力模型适合近似 (Q(s,y,A,e))，不适合直接替代约束和后验更新。后续可把频道视为节点、候选停点视为动作节点，节点特征包括 MEC 中心/半径、粒子熵、\(g_c\)、\(\Delta_c\)、命中概率、距离、切频代价、覆盖缺口和下一入口距离；用 masked set/graph attention 输出候选排序。

训练标签应来自冻结规则策略的共同随机 rollout，目标是剩余时间或相对 baseline 的节省秒数。训练、验证、最终测试按整场种子分离。模型只负责缩小候选集合，最终仍需用高精度 rollout、r20 认证和覆盖证书复核。

## 8. 必须做的消融

至少比较以下四组：

| 方案 | 多频道共享扫描 | 正交候选 | 下一入口代价 |
|---|---:|---:|---:|
| A | 否 | 否 | 现有 |
| B | 是 | 否 | 现有 |
| C | 否 | 是 | 现有 |
| D | 是 | 是 | 联合 |

记录每场总时间、移动距离、跨区长折返、测量/切频次数、每个联合动作的 VOI、共享收益 (S)、正交分数与实际后验面积/半径收缩。若 D 相对 A 在独立场景稳定节省至少 10–15 s/源，再考虑用 attention 替代枚举；若只在压力几何中有效，则把它作为条件策略而非全局默认策略。
