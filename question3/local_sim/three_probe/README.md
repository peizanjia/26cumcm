# 最多三次补测：可证明的条件与有限时域优化

## 结论与次数口径

可以证明**存在最多三次补测即可使候选集合被半径20m圆覆盖的自适应策略**。这里原点已经获得一次示向度，所以是“再测最多3次，总计最多4次测向”。若用户所说“三次”包含原点测向，本证明没有证明只需再测2次。

这个结论需要测点选择条件，不能写成“任意斜前走三次一定达到20m”。也没有证明三次是所需次数的最小上界。

三种不同命题必须分开：

1. 几何保证：对所有符合观测与误差界的目标，末端最小包围圆半径≤20m。
2. 概率保证：在明确的先验/误差分布下，以至少1-δ概率在三次内达到目标。
3. 经验现象：有限样本中未出现超过三次的情况。

本轮同时给出第1项的构造证明与第3项的既有结果回查。

## 1. 为什么测量次数本身不够

设初始示向度0°，后续测点为(100,1)、(200,2)、(300,3)m，三次返回均为0°。目标G₁=(700,0)、G₂=(1400,0)都与全部观测相容：各真实方位与0°差小于1°；令隐藏接收半径为1500m，则全部测点均可收到两个假设目标的信号。

因此候选区域至少包含相距700m的两个点，任何覆盖圆半径至少350m。三个测点虽都朝斜前移动，仍不能有效区分远近。

旧方案的300局也不能当作几何证明：

| 旧斜前策略补测次数 | 局数 |
|---|---:|
| 1 | 103 |
| 2 | 162 |
| 3 | 35 |
| >3 | 0 |

在固定策略、独立同分布实验假设下，零超限/300局给出的单侧95%二项置信上界为 `1-0.05^(1/300)≈0.994%`，不是超限概率等于0，也不是几何半径的保证。

实际反例：旧实验seed20261921，3次补测后、第一次清除前的方位交集最小包围圆半径为27.5449m，clear仍成功。该交集的顶点到所有测点的距离在70.51–1255.22m，均与隐藏R=1500m相容，也没有历史清除失败需要扣除。这不是因为忽略接收半径才虚构出来的歧义。证据见 `outputs/actual_three_probe_counterexample.json`。

回查的300局中，仅122局能由当前保守方位多边形直接认证末端ρ≤20m；35个补测三次的样本中有19个获此认证，其余不应根据clear成功反推ρ≤20m。完整统计见 `old_policy_geometry_audit.json`；该批汇总忽略clear失败排除信息，因而是外包认证统计，不是完整后验区域的精确计数。

## 2. 可用于论文的构造性证明

### 2.1 单次中心测向的收缩引理

已知目标集合K被圆B(c,r)覆盖，且r≤1000m。在圆心c测向，一定有信号。若返回near，则原地清除即可；否则，误差半角为ε的测向扇形把候选集合限制在半径r、半角ε的扇形中。

考虑圆

\[
c'=c+\frac{r}{2\cos\varepsilon}u(\theta),\qquad
r'=\frac{r}{2\cos\varepsilon}.
\]

任一扇形内点写为c+t u(θ+δ)，0≤t≤r、|δ|≤ε。它到c'的距离平方减去r'²为

\[
t^2-2t\frac{r}{2\cos\varepsilon}\cos\delta
\le t^2-tr\le0.
\]

所以该圆覆盖整个扇形，进一步与历史候选集合相交只会缩小区域。设ρ为真实最小包围圆半径，有

\[
\rho_{k+1}\le\frac{\rho_k}{2\cos\varepsilon}.
\]

本题用ε=1.005°，把官方0.01°读数的舍入误差一并保守计入。收缩因子 `1/(2cosε)≈0.500077`。证明不依赖均匀误差或跨测点独立性。

注意必须移动到**包围圆中心**再测向；不能只保证测点“看起来在斜前方”。如果连续两次候选集合都未能认证ρ≤20m，圆心测向会按上述界收缩，因此不会用无效的原地重测获取虚假信息。

### 2.2 第一次补测的统一半径界

初始扇形半径不超过1500m，令

\[
Y=1500\sin\varepsilon=26.30949\text{m}.
\]

初始目标集合包含于矩形 `[0,1500]×[-Y,Y]`。选第一补测点q₁=(a,h)，h>Y，定义

\[
X=\max(|a|,|1500-a|),\qquad
M=\frac{X}{h-Y}.
\]

若

\[
\sqrt{X^2+(h+Y)^2}\le1000,
\]

则矩形中所有可能目标都在接收范围内，故首测一定有信号。本构造h远大于Y，也不会返回near。

对同一示向度下两个候选目标，真实方位差≤2ε。用 `x=a+(y-h)cotθ` 和中值定理，由 `|cotθ|≤M`、`csc²θ≤1+M²` 得到横向直径界

\[
|\Delta x|\le 2YM+2\varepsilon(h+Y)(1+M^2)=W(a,h),
\]

其中ε必须用**弧度**。纵向直径≤2Y，所以对任意首测结果，候选集合均可被半径

\[
\bar\rho_1(a,h)=\frac12\sqrt{W(a,h)^2+4Y^2}
\]

的圆覆盖。这是充分上界，通常大于实际最小包围圆半径。

取q₁=(750,600)m，有

\[
\text{最远接收距离}\le977.1201\text{m}<1000\text{m},
\quad\rho_1\le69.34173\text{m}.
\]

之后在当时最小包围圆中心补测，至多再两次，有

\[
\rho_2\le34.6762\text{m},\qquad
\rho_3\le17.34077\text{m}<20\text{m}.
\]

到末端包围圆中心清除必成功。若中途已经ρ≤20m，立即停止补测；若near，原地清除。由此得到最多3次补测的确定性可行策略。

### 2.3 可连续优化的第一步条件

不必固定第一步为(750,600)。以下两个不等式共同给出一族安全第一步：

\[
\sqrt{X^2+(h+Y)^2}\le1000,\qquad
\bar\rho_1(a,h)\le20(2\cos\varepsilon)^2\approx79.97539.
\]

在这族第一步中选点，后面两次采用圆心测向就有保证。上下反射对称，可只优化h>0，再按需要反射。

这里最大次数由几何构造证明，而不是先假设“三次一定够”再将失败分支删掉。

## 3. 怎样把它放入真正的有限深度决策树

状态至少包含后验b、保守几何集合K、位置s、剩余补测次数h；如果允许冒险clear，还要给试清除次数j设上限。仅限制测向次数，仍可能留下任意多次clear失败的分支，不能自动得到有限动作树。

可设h≤3、j≤1或2，末端必须有一个稳健清除点。定义

\[
\mathcal C(K)=\{q:\sup_{g\in K}\|q-g\|\le20\}.
\]

当K为凸多边形，只需对其顶点检查约束。最终清除位置可解一个小型凸优化问题：最小化 `||q-s||/5+5`，约束 `||q-v_i||≤20`。这比总是走到包围圆圆心更贴合时间目标。

不再允许试探且没有剩余测量时，终端值为

\[
V_{0,0}(b,K,s)=
\begin{cases}
5+\inf_{q\in\mathcal C(K)}\|q-s\|/5,&\mathcal C(K)\ne\varnothing,\\
+\infty,&\mathcal C(K)=\varnothing.
\end{cases}
\]

对h>0，检测分支为

\[
Q_m(q)=\|q-s\|/5+5+
\mathbb E_z[V_{h-1,j}(b_z,K_z,q)].
\]

对j>0，带失败概率的试清除分支为

\[
Q_c(q)=\|q-s\|/5+3+2p_q+
(1-p_q)V_{h,j-1}(b_f,K\setminus B(q,20),q).
\]

可行时还有立即稳健清除的终止动作，取所有合法动作值的最小值。这里动作由公开观测决定；不能针对每条真实目标样本分别预知后选择路径。

严格保证要求**每一个可能观测分支**都有可行收尾；只检查有限训练样本不够。可采用上文解析界作为安全剪枝条件，也可用保守角度区间划分加几何外包逐分支认证。

更一般地定义稳健可达集合：`K∈F₀`当且仅当ρ(K)≤20；`K∈F_h`当存在一个测点，使每一个可能反馈对应的后继集合都属于F_(h-1)（near直接成功）。本轮解析条件只是F₃的一个可证子集，并非所有可行第一步。

**算法建议：有限时域信念状态动态规划＋安全终端策略＋连续动作优化。**三次可行策略可作为rollout的末端策略。探索更快的斜前点时，对其后继分支验证剩余次数内可安全收尾，避免把大侧移的充分条件强加给全部时间最优动作。

## 4. 本轮实际实现的优化算法

为避免把提议写成已完成，具体区分：本轮已经实现的是**第一步二维连续优化，后续使用固定的自适应可证策略**；上节完整的带试清除次数预算动态规划是数学模型，尚未完整实现。

实现的目标为

\[
\min_{a,h}\widehat J_N(a,h)=\frac1N\sum_{i=1}^{N}
T\bigl((a,h),\pi_{\rm center};G_i,R_i,e_{i,1:3}\bigr),
\]

约束为2.3节的两条安全不等式。`π_center`在每次测向后计算实际保守交集：ρ≤20则提前清除，否则到最小包围圆中心补测。最多补测3次。

步骤如下：

1. **样本均值近似（SAA）**：固定128个先验目标与每一步误差样本，所有候选动作共用同一批样本，减少候选间比较的随机波动。这里误差按到访次序耦合，只用于固定样本优化；每条轨迹的新地点误差边际独立均匀。
2. **差分进化（DE）**：对连续变量(a,h)做实数编码的种群搜索，利用向量差变异、交叉、选择降低目标值，不遍历一个预先列出的坐标网格。因为舍入、提前停止和支持顶点变化导致目标分段光滑甚至不连续，当前不用普通梯度直接穿过这些切换。
3. **安全条件检查**：不满足解析约束的点被罚函数拒绝；选出的点再次通过解析条件验证。差分进化只是寻找较好可行解，不提供全局最优认证。
4. **独立验证**：另生成1000个目标，使用本地模拟器按位置固定的误差场，避免训练时固定样本耦合造成虚假收益。

SLSQP只另用于求“满足同样安全条件的最短第一段路程”，提供可行初值，不能把它当作本轮期望时间优化器。它给出约(683.73,551.36)m，而期望时间优化选出不同的点，说明最短第一步不等于总时间最短。

官方算法资料：[SciPy差分进化](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.differential_evolution.html)、[SciPy优化接口](https://docs.scipy.org/doc/scipy/reference/optimize.html)、[MIT动态规划与rollout课程](https://ocw.mit.edu/courses/6-231-dynamic-programming-and-stochastic-control-fall-2015/resources/lecture-notes/)。本节只借用算法定义，三次上界是本方案的独立构造推导。

32代、528次DE函数评估后，保存的较好第一步为

\]

接收距离上界909.5868m；第一补测后半径上界79.97493m；三次补测后半径上界19.999886m。训练均值308.1957秒。DE达到预设迭代预算，`success=false`、`Maximum number of iterations has been exceeded`；因此不能称已经数值收敛，更不能称全局最优。

| 策略 | 独立测试平均时间/s | 1/2/3次补测局数 | 成功 |
|---|---:|---|---:|

配对差为−32.9554秒，标准误0.1117秒。所有末端认证半径≤20m；另对144种边界目标/±1°误差组合进行压力验证，全部成功且≤3次。五项新的几何/反例/边界测试通过。几何证明提供连续情形保证，有限压力测试用于检查实现。

初次试运行在结果序列化时遇到NumPy布尔类型不能JSON编码，已显式转为bool并重跑；没有把那次缺少结果文件的试跑作为最终实验。

**强保证不等于更快。**在旧版相同300个目标和相同误差场上，新保守保证策略平均307.7076秒，旧冒险试清除策略201.0311秒。差距主要反映大侧移安全子集、固定圆心续策和必须认证后清除等限制；不能据此断言任何“三次内完成”的策略都慢。原先(530,-79)策略并没有被本轮更快的新策略替换。

因此论文更合理的组织是：用三次构造证明建立**可行性与计算深度的依据**，用有限时域期望代价模型寻求更快策略，把这一构造作为安全续策或基准；不要把充分条件当作必要条件。
