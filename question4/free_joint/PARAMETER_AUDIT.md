## 真正生效的规划参数

下表“冻结值”来自483.34秒版本，不等于以后所有版本的默认值。“建议研究范围”是本次参数审计的建议边界，**不是已经运行过的连续搜索范围，也不是代码内的自动校验范围**。连续可调量必须为有限数，候选数量/预算必须为合理正整数；要用新选择组验证，不能仅靠区间合法性认定性能或完成性。

| 参数 | 冻结值 | 本方案实际尝试 | 建议研究范围 | 当前用途与选择理由 |
|---|---:|---|---|---|
| `forecast_weight` | 1 | 1、1.2；更早动态试过0.35 | 0.75–1.35 | 共同后续路程的权重；太小会眼前贪心，太大易服从覆盖续策 |
| `unknown_credit_cap_s` | 60 s | 30、60；更早动态试过150、250 | 30–120 s | 一个候选点全部未知频道信用的总上限，避免把离散覆盖收益折算得过大 |
| `unknown_credit_weight` | 0.65 | 未独立调整 | 0.3–1.0 | 搜索预算乘方向质量下降的倍率；总上限常饱和时该维度可能不敏感 |
| `cross_source_weight` | 1 | 未独立调整 | 0–1.5 | 移动前对非主目标已知源的定位收益权重；0不等于禁止到点补扫 |
| `scan_min_net_s` | 2 s | 本冻结分支固定2 | 0–8 s | 非强制测量需达到的净收益；同时影响移动时预测扫频与到点重评 |
| `revisit_penalty_s` | 20 s | 未独立调整 | 0–50 s | 低新颖度回访的软惩罚；有必要的接收恢复仍应能入选 |
| `revisit_radius_m` | 110 m | 未独立调整 | 50–200 m | 回访惩罚的高斯距离尺度，不是硬禁止回访半径 |
| `probe_fraction` | 0.72 | 0.72、0.55，与侧移比例成组 | 0.45–0.90 | 普通单源候选朝后验均值前进的比例；不控制新增近端锚点候选 |
| `lateral_ratio` | 0.25 | 0.25、0.18，与前进比例成组 | 0.12–0.40 | 普通候选侧移 `clip(比例×包围圆半径,18,230)` m |
| `clear_try_radius` | 48 m | 固定48 | 30–70 m | 允许概率性清除候选的几何半径；仍要求估计清除概率≥0.16，失败计费 |
| `max_radio_steps` | 8 | 固定8 | 整数6–12，单独压力验证 | 无线停滞上限；总无线步数还受该值+4限制，失败清除8次也转有限光学补查 |
| `stationary_unknown_cap_s` | 0，关闭 | 0、14，早期组合试验 | 建议先关闭；需要新结构再试 | 到点时允许恢复未受总上限压缩的未知信用；试过盲目放宽反而增加费用 |
| `stationary_unknown_gain` | 0.015，当前不生效 | 0.015、0.08 | 开启上项后再研究0.01–0.10 | 只控制额外到点未知信用；上项为0时此值不影响行为 |
| `posterior_route_mix` | 0，关闭 | 0、0.5、1 | 0–1，需重新单独消融 | 后续服务点从几何中心向条件后验均值插值；不改变保守位置可行域 |
| `approach_clear_boundary` | false | false、true | 布尔开关 | 到达20 m清除可行域近侧边缘；所选实验未胜出而关闭 |
| `adaptive_belief` | true | 与上一动态/分组改进比较 | 布尔消融，正常保持true | 使用128–2048位置积分；未做“仅关闭此项、其他全相同”的完整单因素验证 |
| `elastic_coverage` | true | false、true | 布尔消融 | 在保留连续覆盖证书的条件下，连续移动未来支持点 |
| `near_anchor_probes` | true | 本轮没有独立关闭消融 | 布尔消融 | 加入最近正示向度锚点附近左右短探测，避免只有远端接近候选 |

实际评分近似为：

\[
Q(q,S)=\frac{\|q-p\|}{5}+C_{\rm scan}(S)+\mathbb E C_{\rm clear}
+\lambda_F\widehat L_{\rm future}/5+C_{\rm remaining\ clears}
+\sum_i\Phi_i-\sum_{i\in S}\lambda_i\Delta\Phi_i
-G_{\rm unknown}+P_{\rm revisit},
\]

其中 `Phi_i=0.30×max(rho_i−19.8,0)` 为定位努力的秒数近似，**0.30硬编码于 `frozen_dynamic/information.py`，不是继承参数 `service_tail_weight` 的作用**。接收概率按位置条件朝向/半径相容质量积分；无信号分支不缩小几何包围圆，因此它对未来朝向辨识的价值未被完整折算。上式是有限候选、近似续策的排序函数，不是精确贝尔曼方程求解。

## 候选容量与数值精度

这些参数主要控制近似偏差和规划计算量。更小不一定更快完成任务，更大也不保证决策更好。题目动作时间不包括本地规划墙钟，但计算成本仍应报告。

| 参数/实现常数 | 冻结值 | 已尝试与建议 | 精确含义 |
|---|---:|---|---|
| `integration_min` | 128 | 试过64、128；建议保持128 | 条件位置后验积分的起始面积采样数 |
| `integration_max` | 2048 | 固定2048；先保持 | 每次积分有效样本数不足24时按×4增加，当前序列128→512→2048 |
| 自适应有效样本阈值 | 24 | 硬编码，未调 | ESS=`(Σm)^2/Σm²`，不是正权重点的简单个数 |
| `information_samples` | 3 | 固定3；可做3/5/7精度复核 | 已算好的“条件于命中”分布中取3个位置分位点，预测几何缩小；**不是后验位置总积分数** |
| 假设测角误差分位点 | 3个：−2/3、0、+2/3° | 固定，不改变实际±1°物理误差 | 因此当前跨源几何预测约为3位置×3误差共9个正反馈假设 |
| 单源粗选预测分位点 | 7 | 硬编码，未调 | 旧服务候选初筛使用7个位置分位点，与跨源终评的3×3不同 |
| `coverage_spacing` | 225 m | 固定；可复核150/225/300 | 未知源位置网格间距，当前197个位置 |
| `coverage_directions` | 24 | 固定；可复核16/24/48 | 每位置24个方向状态，只用来引导，不用来认证无源 |
| `candidate_limit` | 20 | 本分支固定；建议12–32 | 快速初筛的基准入围数；随后补保每个活跃源与一个强制覆盖候选，**不是最终绝对上限** |
| `service_candidates_per_source` | 3 | 本分支固定；建议1–5 | 从旧服务候选排序保留的每源动作数；新增近端候选另行加入 |
| `frontier_candidates` | 14 | 本分支固定；建议6–24 | 方向缺口候选上限 |
| `shared_candidates` | 8 | 本分支固定；建议2–12 | 多源共享位置候选上限 |
| `waypoint_candidates` | 8 | 本分支固定；正值4–12可消融 | 长于450 m的移动段取0.45/0.70比例中途点；这些点须真实停测才有信息 |
| `refine_candidates` | true | 本分支固定；可布尔消融 | 普通非强制测量赢家附近再做局部坐标细化 |
| `refine_step_m` | 70 m | 本分支固定；建议30–120 m | 在当前赢家的±x、±y方向各偏移一个步长，非连续全局优化 |
| `forecast_passes` | 1 | 固定；可试1–4 | 候选未来共同路线NN初值后执行2-opt改善的轮数 |
| 覆盖移动支持的搜索力度 | 每轮前4点，每吸引方向0.25/0.10/0.04比例 | 硬编码，未调 | 吸向当前位置、相邻点中点和最近已知源；路程至少降1 m且连续证书仍成立才接受 |
| 近端锚点距离 | `min(100,0.2d)`、`min(220,0.4d)`、`min(400,0.6d)` m | 硬编码，未调 | d为最近正反馈到几何中心距离；每长度左右侧移`max(15,0.55×长度)` m |
| 保守圆外接多边形 | 48边 | 固定，不以较少费用为由放宽 | 保持真实位置不被数值近似排除 |
| 规划坐标舍入 | 普通候选0.01 m；证书支持保留完整精度 | 固定 | 证书支持不能随意舍入，否则可能破坏短边/包围边界 |

`waypoint_candidates=0`不宜直接当作可靠“关闭中途点”的开关：冻结基类循环在加入候选以后才检查数量，因此需要先修正或明确验证零值语义，才能把0纳入消融。其他数量参数也应检查实现边界，不应仅因为类型是整数就搜索到0。

以下字段会出现在全展开JSON中，容易误以为已控制当前策略。已沿实际调用链核对：`free_joint.Planner → frozen_dynamic.Planner → full_mission.Planner`；动态层重写 `choose`、`assess_stop`、`run` 后，旧固定站调度入口没有被调用。

|---|---:|---|

| `inner`、`outer` | 980、1870 m | 仅用于基类初始化的25点覆盖检查，随后固定站列表被清空；**不决定free_joint实际未来补盲点半径**。改坏值仍可能导致构造时证书异常，因此并非完全无副作用 |

## 物理规则、建模先验与完成性限制

| 类别 | 当前值/规则 | 是否可以为提分而优化 |
|---|---|---|
| 题目物理：位置域 | 源位于半径1800 m圆盘，机器人允许到圆外测量 | 不可以 |
| 题目物理：接收半径 | 每源固定在1000–1500 m之间 | 不可以 |
| 题目物理：发射 | 全向或固定180°半平面，朝向未知 | 不可以 |
| 题目物理：动作 | 移动5 m/s，测量5 s，切频道1 s；清除成功5 s、失败3 s | 不可以 |
| 题目物理：接近/清除 | `near`≤5 m仍要求接收到；光学清除≤20 m且与朝向无关 | 不可以 |
| 题目物理：测角 | 同频道同精确位置的±1°误差固定；显示舍入0.01° | 不可以；同点重测不是独立噪声样本 |
| 几何保守量 | 示向度半角1.005°；保证清除使用19.8 m留裕量 | 不能通过减小误差或扩大清除范围伪造收益 |
| 频道与数量 | 20频道，10–16源，每源占不同频道；发现16源可停止未知搜索 | 不可以；策略不知道实际源数 |
| 本地生成分布 | 位置圆盘均匀、半径均匀、方向均匀，定向源比例约0.55 | 是本地评价假设，不是策略可窃取的真值；改变分布要单列稳健性组 |
| 已知源条件积分先验 | 代码积分相对全向/定向采用相同初始类型权重 | 这是建模近似，不等于已从题目得到精确比例；未做类型先验寻优 |
| `max_commands` | 7000次 | 异常防护；不能降低后只统计提前停止费用 |
| `max_dynamic_stops` | 500次 | 异常防护；达到上限应报未完成，不以成功子集计算主均值 |
| 无线失败后的有限补查 | 首次示向度坐标系的122个光学覆盖候选，排除已试或与保守区域不相交点 | 保持有限性与真实清除反馈，不能用数值后验稀疏当作不存在 |
| 完成证书 | 每个未知频道真实负反馈点形成全域连续短边三角网证书，或公开16源上限 | 不可以用225 m×24方向离散状态清空代替 |

零积分质量说明采样未捕获相容区域，不代表真实源不存在；当前保留带标签的均匀/0.5接收启发式以继续规划，仍靠保守几何、真实清除与连续覆盖作保证。`proof.py`里的自适应局部凸包分区是未接入执行的证书实验，不能把其参数记成已生效算法。

## 从原方案改进的动机与做法

| 原方案问题 | 已实施做法 | 保留的边界 |
|---|---|---|
| 固定24搜索站决定大部分路线，途经服务点无法自然替代搜索点 | 逐频道维护未知位置×朝向残余，生成方向前沿与几何补点；执行一步后重建共同续策 | 仍需可行几何初值和连续证明，尚非完全无几何先验 |
| 初始方向域虽然动态，几何补点坐标仍过于僵硬 | 接受保留全部相关频道覆盖证书、能缩短共同路程的未来点连续位移 | 局部搜索前4点，不是整个连续路线全局求最短 |
| 长窄示向区域32位置点漏掉近端相容区域，命中概率过度确定 | 位置积分128→512→2048自适应加密，条件朝向和半径段解析积分 | 数值后验用于评分，不用于排除真实可能性 |
| 单纯朝估计中心前进容易走到定向源背面 | 增加最近正反馈锚点的左右近端短探测，与普通服务候选一起评分 | 没有把单个朝向估计当作真值；候选长度仍有启发式常数 |
| 当前目标主导选点，忽略其他源可同时缩小的范围 | 移动前对每个已知源估计条件命中与几何缩小，累计跨源收益；加入共享和中途候选 | 初筛和有限预测仍可能错过更好的连续位置 |
| 走过某点就默认有信息，或到点按原名单一直扫 | 仅真实停点测量产生观测；每条反馈后重评频道与同点清除，记录回访并加软惩罚 | 额外放宽未知扫频已试验变慢，当前关闭 |
| 共享/细化入口绕过单源无线恢复预算，造成长时间失联 | 所有无线入口共用资格门槛，预算耗尽进入有限光学补查 | 阈值仍是启发式，需要难例和完整计费验证 |

算法文字与整体流程图见 [README.md](README.md)。其核心是“更新公开信念→重新设计未来点与服务候选→共同秒数评分→只执行一步→到点逐反馈重评”，而不是先锁定一个源再独立追踪到清除。

## 为什么还不能说没有优化空间

独立100场483.34秒/源中，移动338.11秒/源约占69.95%；最后清除之后还平均花383.1秒/场确认未知频道无源。直接方向前沿只有13次移动，而连续覆盖补全2290次，说明现有搜索仍主要由保证覆盖的续策引导。最差退步例20293054寻找第16源显著更晚。这些事实支持继续研究，但不能直接把相关费用全算作可实现节省。

建议本轮优先对真正生效的约7维做共同场景贝叶斯搜索：续策权重、未知信用上限、跨源权重、扫频净门槛、普通前进/侧移比例、回访惩罚。固定物理、积分精度和连续证书，避免参数自由度过多。每个候选按完整任务每场`T/N`等权均值计分；有任一未完成须惩罚或淘汰，不能将未完成丢掉后报告均值。

参数确定后，再考虑结构改动：让“在当前服务点补扫一组频道”只有在实际能替代连续覆盖支持、减少后续路线时获得额外价值；更完整地计价朝向辨识与接收失败恢复。这些超出原参数微调，不应提前写成已实现。最后用没有参与选择的新共同种子对照483.34版本，保留全清率、尾部费用和差案例回放。

即使贝叶斯搜索达到预算且最后数轮没有改善，也只能称“本轮搜索范围与预算内的最佳已测配置”。有限启发式、有限场景和有限搜索不能证明全局最优，不能保证以后再无改进。
